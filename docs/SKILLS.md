# `wrs` skill manifest

The library's manipulation vocabulary for a task-decomposition layer: atomic actions + the geometric queries that couple them. Auto-generated by `tools/gen_skill_manifest.py` from the catalog in `wrs/skills.py` (targets validated against the source); edit the catalog, then re-run.

Failure stages reference the `diag=` channel (`wrs.motion.core.diagnosis`); a `Recipe` surfaces the failed step's stage as `recipe.failure`.

## Setup

### `build_collider`
_Build the collision world every planning skill runs in: robot (+ mounted gripper) + static fixtures + obstacles._

- target: `wrs.manipulation.arm.SingleArmManipulation.build_collider`
- signature: `build_collider(self, fixtures=(), objects=(), *, margin=0.0)`
- pre: robot constructed; end effector mounted
- pre: the object about to be PICKED is NOT included (it is grasped, not an obstacle)
- post: a compiled collider, passed explicitly (collider=) to every planning call
- returns: MJCollider

## Motion actions (plan; return MotionData or None)

### `moveto`
_Free collision-planned travel (RRT) to a config or a tcp pose, carrying whatever is held._

- target: `wrs.manipulation.arm.SingleArmManipulation.moveto`
- signature: `moveto(self, goal, *, collider, tcp=None, constraints=(), start_qs=None, ee_qpos=None, max_iters=2000, time_limit=3.0, shortcut=True, diag=None)`
- recipe verb: `Recipe.moveto`
- pre: collider built; start config valid
- pre: pose goals need a tcp (the working frame)
- post: arm at the goal; held object carried collision-checked
- returns: MotionData, or None (why: diag= / recipe.failure)
- on `ik`: zero candidates: the pose is out of reach -- change the pose or the base; all invalid: it is blocked -- change the world or the grasp
- on `start_invalid`: the world is mis-set-up (start already colliding)
- on `goal_invalid`: the explicit goal config collides -- pick another
- on `rrt`: no path in budget -- retry with a larger budget or another goal IK branch

### `linear`
_Straight cartesian leg of the tcp (no RRT) -- the mating / insertion / press move._

- target: `wrs.manipulation.arm.SingleArmManipulation.insert`
- signature: `insert(self, goal_pos, goal_rotmat, *, collider, tcp, start_qs, constraints=(), start_pos=None, start_rotmat=None, granularity=0.005, **kw)`
- recipe verb: `Recipe.linear`
- pre: collider built; the line start is the current tcp pose of start_qs (or given explicitly)
- post: tcp moved straight to the goal pose
- returns: MotionData, or None (why: diag= / recipe.failure)
- on `cartesian`: ik broke: the line exits the workspace -- shorten it or reorient; blocked: an obstacle crosses the line -- clear it or approach from elsewhere

### `approach`
_RRT to a pre-grasp then a straight descent along the approach axis -- how every pick and place reaches its target._

- target: `wrs.manipulation.arm.SingleArmManipulation.approach`
- signature: `approach(self, goal_pos, goal_rotmat, *, collider, tcp, constraints=(), start_qs=None, **kw)`
- pre: collider built; grasp/goal pose chosen (e.g. from reason_grasps)
- post: tcp at the grasp pose, having come in straight
- returns: MotionData, or None (why: diag=)
- on `ik`: pre-grasp unreachable or blocked -- try another grasp
- on `rrt`: travel found no path -- larger budget or another grasp
- on `cartesian`: descent broke or is blocked -- another approach direction or grasp

### `depart`
_Straight retreat along the approach axis (back out the way the hand came in), optionally RRT-parking after._

- target: `wrs.manipulation.arm.SingleArmManipulation.depart`
- signature: `depart(self, start_pos, start_rotmat, *, collider, tcp, start_qs, constraints=(), **kw)`
- pre: at a grasp/contact pose (start_qs required)
- post: tcp retreated depart_distance; optionally parked at end_qs
- returns: MotionData, or None (why: diag=)
- on `cartesian`: retreat blocked -- another depart direction
- on `rrt`: park leg found no path -- larger budget or another park

## State actions (mutate the held state)

### `hold`
_Take the object into the end effector at the current config; subsequent motion carries it collision-checked._

- target: `wrs.manipulation.arm.SingleArmManipulation.hold`
- signature: `hold(self, obj, qpos, *, collider, exclude=False)`
- recipe verb: `Recipe.hold`
- pre: arm AT the grasp config (plan there first)
- pre: object resting at its grasp pose
- post: object mounted on the gripper; collider refreshed
- returns: None (state mutation)

### `release`
_Drop the held object (open + unmount); subsequent motion is empty-handed._

- target: `wrs.manipulation.arm.SingleArmManipulation.release`
- signature: `release(self, obj, *, collider)`
- recipe verb: `Recipe.release`
- pre: object currently held; arm at the place pose
- post: object free at its current pose; collider refreshed
- returns: None (state mutation)

## Queries (produce information -- the reasoning layer)

### `reachable`
_Cheap feasibility gate: the nearest collision-free IK for a pose, WITHOUT motion planning -- vet every key pose of a plan before paying for any leg._

- target: `wrs.manipulation.arm.SingleArmManipulation.reachable`
- signature: `reachable(self, goal, *, collider, tcp, constraints=(), ref_qs=None, diag=None)`
- pre: collider built
- returns: a config, or None (diag counts split unreachable vs blocked)

### `reason_grasps`
_Which grasps are reachable + collision-free at ALL the given object poses -- THE coupling constraint of pick-then-place; an empty result is what calls for a regrasp._

- target: `wrs.manipulation.arm.SingleArmManipulation.reason_grasps`
- signature: `reason_grasps(self, grasps, obj_pose_list, *, collider, constraints=(), which='pre', **kw)`
- pre: object-local grasps generated (generate_grasps) or loaded
- pre: collider built
- returns: {gid: [config at each pose, ...]}; empty -> no single grasp works everywhere -- insert an intermediate placement (regrasp) or add grasps

### `generate_grasps`
_Generate object-local antipodal (2-point pinch) grasp candidates for a gripper on a mesh._

- target: `wrs.grasp.antipodal.antipodal`
- signature: `antipodal(gripper, target_sobj, density=0.02, normal_tol_deg=20, roll_step_deg=30, clearance=0.002, score_weights=(0.7, 0.3), exclude_regions=None, pre_open=0.5)`
- pre: gripper model; object SceneObject with mesh
- returns: list of Grasp (object-local); empty -> loosen density / tolerances, or the object does not fit the jaw

### `stable_placements`
_The poses an object can REST in -- the intermediate placements a regrasp routes through._

- target: `wrs.grasp.placement.compute_stable_poses`
- signature: `compute_stable_poses(vs, fs, facets, com=None, stable_thresh=7.0)`
- pre: object mesh (+ optional center of mass)
- returns: stable resting poses with support facets

## Canonical compositions

### `pick_and_place`
_home -> pick -> lift -> transfer -> place -> release -> retreat, choosing a grasp feasible at BOTH ends (reason_grasps inside). The one canonical composition; other shapes are written as Recipes, not added as skills._

- target: `wrs.manipulation.arm.SingleArmManipulation.pick_and_place`
- signature: `pick_and_place(self, obj, grasps, pick_pose, place_pose, *, collider, **kw)`
- pre: grasps generated; pick/place poses known; collider WITHOUT the object
- post: object resting at the place pose; arm retreated
- returns: MotionData, or None (no common grasp fully planned -- regrasp via stable_placements, or add grasps)
