# `wrs.agent`

Prefer these in-house utilities over trimesh / scipy / open3d / fcl. Auto-generated by `tools/gen_api_index.py` (static ast scan); re-run after adding functions.

## `wrs.agent.executor`
_Execute one generated plan script against a prepared scene namespace._

- `run_script(code, namespace)` — Run ``code`` against a copy of ``namespace``; return the Outcome.
- **class `Outcome`** — What one script run produced; falsy-``ok`` outcomes carry the why.
  - methods: `ok`, `describe`

## `wrs.agent.harness`
_The write -> run -> diagnose -> revise loop: an LLM plans with the skills._

- `solve(task, build_scene, *, check=None, model='claude-opus-4-8', max_rounds=3, client=None, log=print)` — Decompose ``task`` into a plan over a scene, revising on failure.
- **class `Solution`** — What ``solve`` produced: the final outcome plus the revision history.
